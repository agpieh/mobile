## Mô tả
Thực hành tạo 3 hình vuông được căn giữa màn hình (theo cả chiều dọc và ngang). Mỗi hình vuông có một màu nền riêng biệt, nhưng các thuộc tính kích thước dùng chung (width, height) chỉ được định nghĩa một lần duy nhất bằng cách kết hợp array style.
